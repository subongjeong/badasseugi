# 받아쓰기 공책

바로 쓰기 👉 **바로 쓰기: https://subongjeong.github.io/badasseugi/**

초등학교 저학년 받아쓰기 연습장입니다. 폰·태블릿·노트북 브라우저에서 바로 쓸 수 있고, 설치나 로그인이 필요 없습니다.

아이들이 받아쓰기에서 가장 많이 틀리는 건 **들리는 소리와 쓰는 글자가 다른 받침**입니다. `맡은`이 [마튼]으로, `값`이 [갑]으로, `있나요`가 [인나요]로 들리니까 소리 나는 대로 쓰게 되죠. 이 공책은 그 차이를 먼저 눈으로 익히고, 듣고 써 보고, 틀린 받침만 다시 연습하도록 만들었습니다.

## 주간 연습 순서 (목요일 시험 기준)

| 단계 | 권장 요일 | 하는 일 |
|---|---|---|
| 1. 소리와 글자 익히기 | 금~월 | 받침 낱말 카드: 글자, 소리 [발음], 받침 규칙, `것 = 거 + ㅅ` 분해 |
| 2. 받침 낱말 받아쓰기 | 화 | 헷갈리는 낱말만 하나씩 듣고 쓰고 바로 확인 |
| 3. 실전 모의시험 | 수 | 문장 전체를 다 쓰고 한꺼번에 채점 |
| 4. 틀린 것 마지막 점검 | 목 아침 | 틀린 문장과 아직 헷갈리는 낱말만 |

오늘 요일에 맞는 단계가 자동으로 강조됩니다.

## 채점

- 원고지 칸에 내 답과 바른 답을 나란히 보여 주고, 틀린 칸은 빨강, 고친 칸은 초록으로 표시합니다. `∨`는 띄어쓰기 자리입니다.
- 틀린 이유를 **띄어쓰기 / 문장부호 / 글자**로 나눕니다.
- 받침 낱말은 **소리 나는 대로 썼는지**(`마튼`), **받침만 틀렸는지**(`맏은`)를 구분해서 알려 줍니다.
- 받침 규칙별(넘어가는 받침, 바뀌는 받침, 두 개 받침, ㅎ 만나면 세게, 된소리) 틀린 횟수를 모아 보여 줍니다.
- 헷갈리는 낱말은 **두 번 연속 맞히면** 목록에서 빠집니다.

## 다음 주 문장으로 바꾸기

처음 화면 아래 **문장 바꾸기 · 급수 추가**에서 한 줄에 한 문장씩 넣습니다. 발음을 `[대괄호]`로 붙이면 받침 카드와 오답 분석이 정확해집니다.

```
냄새 맡은 값 [냄새 마튼 갑]
끝에 있습니다. [끄테 읻씀니다]
```

발음을 안 붙여도 받침 규칙(연음, 겹받침, ㅎ 축약, 대표음)을 자동으로 찾아 카드를 만들지만, 표준 발음을 적어 주는 쪽이 더 정확합니다. 급수 공책 사진을 AI에게 보여 주고 "한 줄에 `문장 [표준 발음]` 형식으로 적어 줘"라고 하면 빠릅니다.

## 알아 둘 점

- 문장은 브라우저의 음성 합성(Web Speech API)으로 읽습니다. 한국어 음성이 없는 기기에서는 "보호자: 문제 보기"를 눌러 직접 읽어 주세요. iPad·iPhone·Android·Chrome은 대부분 한국어 음성이 있습니다.
- 기록은 그 기기의 브라우저(localStorage)에만 저장됩니다. 서버로 아무것도 보내지 않습니다.
- 기본 문장은 2학년 받아쓰기 4급 「마음을 전해요」입니다.
