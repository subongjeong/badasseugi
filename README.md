# 받아쓰기 공부

👉 **바로 쓰기: https://subongjeong.github.io/badasseugi/**

초등학교 저학년 받아쓰기 연습 웹앱입니다. 원래 우리 집 시현이(2학년)의 목요일 받아쓰기 시험 준비용으로 만들었고, 누구나 쓸 수 있게 공개합니다. 폰·태블릿·노트북 브라우저에서 바로 열립니다.

아이들이 받아쓰기에서 가장 많이 틀리는 건 **들리는 소리와 쓰는 글자가 다른 받침**입니다. `맡은`이 [마튼]으로, `값`이 [갑]으로, `있나요`가 [인나요]로 들리니까 소리 나는 대로 쓰게 되죠. 그 차이를 먼저 눈으로 익히고, 듣고 종이에 써 보고, 틀린 받침만 다시 연습하도록 만들었습니다.

## 쓰는 방법

1. 보호자가 이메일로 가입·로그인합니다. (로그인 없이 이 기기에만 저장하며 쓸 수도 있어요.)
2. 아이 이름을 추가합니다. 한 계정에 여러 아이를 따로 기록할 수 있고, 화면 제목이 "시현이의 받아쓰기 공부"처럼 바뀝니다.
3. 요일에 맞는 단계를 누릅니다.

| 단계 | 권장 요일 | 하는 일 |
|---|---|---|
| 1. 소리와 글자 익히기 | 금~월 | 받침 낱말 카드: 글자, 소리 [발음], 받침 규칙, `맡 = 마 + ㅌ` 분해 |
| 2. 받침 낱말 받아쓰기 | 화 | 헷갈리는 낱말만 하나씩 듣고 쓰고 바로 확인 |
| 3. 실전 모의시험 | 수 | 문장 전체를 다 쓰고 한꺼번에 채점 |
| 4. 틀린 것 마지막 점검 | 목 아침 | 틀린 문장과 아직 헷갈리는 낱말만 |

### 종이 공책에 쓰기 (기본)

화면이 문장을 두 번 읽어 주면 아이는 실제 시험처럼 공책에 연필로 씁니다. 다 쓰면 원고지 칸으로 바른 답이 나오고, 공책과 한 칸씩 비교해 ○/✗를 누르고 어디가 틀렸는지(받침 낱말, 띄어쓰기, 문장부호, 다른 글자) 고릅니다. 설정에서 **화면에 입력**으로 바꾸면 키보드로 쓰고 자동 채점됩니다(소리 나는 대로 썼는지, 받침만 틀렸는지까지 구분).

### 기록 분석

로그인하면 모든 연습이 계정에 저장되고 어느 기기에서든 이어집니다.

- 연습 횟수, 최근 4주 연습한 날, 받침 낱말 정답률, 마지막 모의시험 점수
- 모의시험 점수 흐름과 실제 목요일 시험 점수(처음 화면에서 입력)
- 받침 규칙별 정답률: 넘어가는 받침 · 바뀌는 받침 · 두 개 받침 · ㅎ 만나면 세게 · 된소리 · 줄여 들리는 말
- 자주 틀린 낱말 순위와 틀린 이유
- 급수별 연습 횟수 · 모의시험 최고 점수 · 실제 시험 점수

헷갈리는 낱말은 **두 번 연속 맞히면** 목록에서 빠집니다.

## 다음 주 문장 넣기

처음 화면 아래 **문장 바꾸기 · 급수 추가**에서 한 줄에 한 문장씩 넣습니다. 발음을 `[대괄호]`로 붙이면 받침 카드와 오답 분석이 정확해집니다.

```
냄새 맡은 값 [냄새 마튼 갑]
끝에 있습니다. [끄테 읻씀니다]
```

발음을 안 붙여도 받침 규칙(연음, 겹받침, ㅎ 축약, 대표음)을 자동으로 찾아 카드를 만듭니다. 급수표 사진을 AI에게 보여 주고 "한 줄에 `문장 [표준 발음]` 형식으로 적어 줘"라고 하면 빠릅니다.

기본으로 2학년 4급 「마음을 전해요」가 들어 있습니다.

## 알아 둘 점

- 문장은 브라우저 음성 합성(Web Speech API)으로 읽습니다. 한국어 음성이 없는 기기에서는 "보호자: 문제 보기"를 눌러 직접 읽어 주세요.
- 로그인 데이터는 Supabase에 저장되고, 행 수준 보안(RLS)으로 각 보호자 계정만 자기 아이 기록을 읽고 쓸 수 있습니다.
- 로그인 없이 쓰면 그 기기 브라우저(localStorage)에만 저장됩니다.

## 직접 띄우기 (포크)

빌드 도구 없는 정적 사이트입니다: `index.html`, `style.css`, `app.js`, `config.js`.

1. 이 레포를 포크하고 GitHub Pages를 켭니다(Settings → Pages → main / root).
2. 자기 [Supabase](https://supabase.com) 프로젝트를 만들고 SQL Editor에서 `supabase/schema.sql`을 실행합니다.
3. `config.js`의 `supabaseUrl`, `supabaseKey`(publishable 키)를 자기 값으로 바꿉니다.
4. Supabase → Authentication → URL Configuration에서 Site URL을 자기 Pages 주소로 바꿉니다(가입 확인 메일 링크가 그 주소로 돌아옵니다).
